# Job Application Tracker

A simple Streamlit web app to manage your job applications — add, search, filter, export, and delete entries easily.

## Features
- Add job applications with title, company, date, and notes
- Filter and search your jobs
- Export data to Excel
- Clean UI built with Streamlit

## Tech Stack
- **Python**
- **Streamlit**
- **Pandas**

## Run locally
```bash
pip install -r requirements.txt
streamlit run app.py
